<b>1️⃣ ElevenLabs 发布 Guardrails 2.0：三层防护架构让企业 AI 语音 Agent 更可控</b>
<i>🕐 06-20 · 距今约 19 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
ElevenLabs 为 ElevenAgents 平台推出 Guardrails 2.0 重设计安全控制层，以三层保护机制防止 AI 语音 Agent 偏离预设脚本：① Focus Guardrail 在整个对话中持续强化 Agent 原始指令；② 操控检测层拦截 prompt 注入等对抗性输入，可自动终止风险对话；③ 策略合规层在响应发出前校验所有内容是否符合自定义业务规则。企业可用自然语言定义专属合规策略并在实时对话中执行；Focus、Manipulation、Content 三项基础 Guardrail 对全部 ElevenAgents 用户免费，自定义策略按 LLM 用量计费。

<b>📊 关键数据</b>
- 防护层数：3 层（Focus + Manipulation + Content）
- 基础三层：全 ElevenAgents 用户 0 成本开启
- 自定义策略：自然语言定义，实时执行，按用量计费
- 入口：Agent 设置 → Security 选项卡，即日生效

<b>💡 为什么重要</b>
企业 Voice Agent 最大风险是被用户诱导越权或偏题，Guardrails 2.0 将合规控制内嵌至运行时；ElevenLabs 以此强化企业级护城河，是 Voice Agent 平台从"好用"走向"合规可控"的关键里程碑。

<b>2️⃣ Soniox 发布 v5 Real-Time STT：60+ 语言、Pareto 最优精度+延迟、同类专有模型最低价</b>
<i>🕐 06-20 · 过去 24 小时内</i>
<blockquote expandable><b>📝 发生了什么</b>
Soniox 发布新一代实时流式语音转文字模型 stt-rt-v5，在 Artificial Analysis 流式 STT 基准（AA-WER Streaming）上达到同类专有模型中精度与延迟 Pareto 最优、价格最低的组合。v5 全面提升：60+ 语言转录精度、重新设计实时说话人分离、改进多语言识别、支持 3,600+ 语言对实时翻译、更快语义端点检测。与现有 Soniox Real-Time API 100% 兼容，仅需将 model 参数从 stt-rt-v4 改为 stt-rt-v5。前一代 stt-rt-v4 将于 2026-06-30 退役，届时自动路由至 v5，无服务中断。

<b>📊 关键数据</b>
- 语言支持：60+ 语言转录，3,600+ 语言对实时翻译
- 性能定位：Pareto 最优（精度 + 延迟），同类专有模型最低价
- v4 退役日：2026-06-30（自动切换，无 API 变更）
- 迁移成本：零——仅改一个 model 参数名

<b>💡 为什么重要</b>
实时 STT 是语音 Agent 基础能力，Pareto 最优意味着在精度不降前提下延迟最优成本最低；Soniox v5 直接向 Deepgram、AssemblyAI、ElevenLabs Scribe 施压，有望改变企业 Voice Agent 的 STT 供应商选择格局。
