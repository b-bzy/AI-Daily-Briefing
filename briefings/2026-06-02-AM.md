<b>1️⃣ Microsoft Build 2026：MAI-Voice 2 多语言 TTS 与 MAI-Transcribe 1.5 正式发布</b>
<i>🕐 06-02 · 今日开幕</i>
<blockquote expandable><b>📝 发生了什么</b>
Microsoft 于今日 Build 2026 开发者大会（旧金山 Fort Mason）正式发布 MAI-Voice 2 和 MAI-Transcribe 1.5，通过 Azure AI Foundry 向开发者开放。MAI-Voice 2 为自研 TTS 的多语言升级版，语言支持从英语扩展至 16 种（含德、法、西、印地、日、韩、葡、土、越、中等），情感维度新增 angry、confused、embarrassed 等细粒度控制；MAI-Transcribe 1.5 在 4 月发布的 MAI-Transcribe-1（已覆盖 25 个语言最低词错率记录）基础上再度提升准确率，可为 AI 会议摘要、通话分析和语音 Agent 提供更精准的转写底座。

<b>📊 关键数据</b>
- MAI-Voice 2：16 种语言，情感维度新增 angry / confused / embarrassed
- MAI-Transcribe 1.5：基于 25 语言最低词错率记录再升级
- 发布渠道：Azure AI Foundry 开发者 API

<b>💡 为什么重要</b>
微软加速建立独立于 OpenAI/ElevenLabs 的自有语音模型栈，MAI-Voice 2 多语言与情感扩展直接竞争企业级 TTS 市场，同时为 Teams、Copilot 降低外部 API 成本。

<b>1️⃣ Anthropic 向 SEC 秘密递交 IPO 招股书——$9650 亿估值，剑指史上最大 AI 科技 IPO 之列</b>
<i>🕐 06-01 · 距今约 12 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
Anthropic 于 2026 年 6 月 1 日正式向 SEC 秘密递交 Form S-1 招股书，目标 2026 年 10 月公开上市。最新 H 轮（2026-05-28 敲定，融资 $650 亿）确定估值 $9650 亿，超越 OpenAI 约 $8520 亿，成为全球最高估值 AI 实验室。公司目标最高以 $1.75–1.8 万亿估值挂牌，潜在融资规模达 $750 亿，若成功将成科技史上最大 IPO 之一。法律顾问为 Wilson Sonsini（曾主导 Google 2004 年 IPO）。OpenAI 约于 5 月 22 日已同步秘密递交 S-1，目标 2026 年 9 月上市，估值 $1 万亿以上——两大顶级 AI 实验室将同年 IPO。

- S-1 递交日：2026-06-01（秘密递交）

- 年化营收运行率：$470 亿（同比增长约 80 倍）
- 目标 IPO 估值上限：$1.8 万亿；潜在融资额 $750 亿
- 目标上市时间：2026 年 10 月

<b>💡 为什么重要</b>
两大顶级 AI 实验室同年 IPO，将为 AI 产业提供前所未有的公开市场估值锚点，直接重塑企业 AI 采购决策与竞争格局，并引发 AI 基础设施与应用子领域的估值重定价。

<b>2️⃣ [更新] Microsoft Build 2026 主题演讲落地：Windows Agent Framework 开源，Azure Agent Mesh 与 Copilot Workspace 正式 GA</b>
<i>🕐 06-02 · 今日开幕</i>
<blockquote expandable><b>📝 发生了什么</b>
Build 2026（旧金山 Fort Mason，6月2-3日）Satya Nadella 主题演讲正式宣告 Windows 成为 Agent 平台：Windows Agent Framework（WAF）v1.0 以 MIT 协议开源，Agent 作为操作系统级原生构件运行；Azure Agent Mesh 上线，支持跨 M365、Azure 与第三方应用的 Agent 协作网络；Copilot Workspace 正式 GA（退出 Beta），开发者以自然语言描述需求后 Copilot 可自主完成跨文件修改并开 PR；Windows Agent Store 上线（85% 开发者分成）。Project Polaris（微软自研 MoE 编码模型）官方确认将于 2026 年 8 月替换 GitHub Copilot 默认模型，彻底降低对 OpenAI 外部 API 的依赖。

<b>📊 关键数据</b>
- WAF v1.0：MIT 开源，操作系统级 Agent 原生 API
- Azure Agent Mesh：跨生态 Agent 协作，覆盖 M365 + Azure + 第三方
- Copilot Workspace：正式 GA（原 Beta）
- Windows Agent Store：85% 开发者分成
- Project Polaris：2026 年 8 月替换 GitHub Copilot 默认模型（正式确认）

<b>💡 为什么重要</b>
Windows 级别 Agent Runtime 意味着 Agent 不再是云端附加功能，而是操作系统原生 API，将倒逼 Apple 与 Google 加速本地 Agent 基础设施布局，并为企业 On-device AI Agent 部署打开新通道。
