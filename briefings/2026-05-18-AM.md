<b>1️⃣ OpenAI 重组产品线：Greg Brockman 永久出任全产品负责人，ChatGPT + Codex + API 三合一</b>
<i>🕐 05-16 · 距今约 36 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
OpenAI 联合创始人兼总裁 Greg Brockman 将永久担任全产品战略负责人，统一 ChatGPT、Codex 和开发者 API 为单一产品组织。Codex 构建者 Thibault Sottiaux 出任核心产品与平台负责人，原 ChatGPT 负责人 Nick Turley 转向企业产品。此次重组在 Google I/O 开幕前 4 天宣布，内部目标是打造统一的 Agentic "超级应用"，并为 Q4 2026 IPO 简化产品叙事。Brockman 表示："我们整合产品投入，以最大专注度迈向 Agentic 未来。"

<b>📊 关键数据</b>
- 时机：Google I/O 2026 前 4 天（05-16 宣布）
- IPO：预期 Q4 2026，目标估值约 $8,520 亿
- 产品方向：ChatGPT + Codex + Atlas 浏览器合并为统一 Superapp

<b>💡 为什么重要</b>
标志 OpenAI 从多产品线扩张转向 Agentic 平台聚焦；Brockman 在 4 月初以代理身份临时接管后正式转正，显示组织决策已定。时机紧贴 Google I/O，防御意图明显；统一平台叙事也有助于 IPO 路演中向机构投资者呈现更清晰的商业逻辑。

<b>2️⃣ xAI 发布 Grok Build：直线对标 Claude Code 的多 Agent 编程 CLI 进入 Beta</b>
<i>🕐 05-17 · 距今约 8 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
xAI 推出 Grok Build，定位为面向专业软件工程师的 Agentic CLI，可规划项目、编写/编辑文件、执行 Shell 命令并从自然语言指令构建完整应用。底层 Grok 4.3 beta 支持 200 万 Token 上下文；内置"计划模式（Plan Mode）"，允许开发者在 AI 实际执行前审批变更；最多可同时启动 8 个并发子 Agent 协同工作。Elon Musk 亲自在 X 上号召公测用户参与早期 Beta。

<b>📊 关键数据</b>
- 底层模型：Grok 4.3 beta，2M Token 上下文
- 并发 Agent 上限：8 个
- 定价：SuperGrok Heavy $299/月（限时 $99/月，前 6 个月）
- 竞品：Anthropic Claude Code、OpenAI Codex

<b>💡 为什么重要</b>
xAI CEO Elon Musk 此前公开承认在编程能力上落后对手；Grok Build 是正面追赶的关键部署。多 Agent 并发设计对大规模代码库重构可能形成差异化；若 Grok 5 于 2026 年中如期发布，底层能力跃升将直接放大 Grok Build 竞争力，届时编程 Agent 三强格局将迎来真正检验。
