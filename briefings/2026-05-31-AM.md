<b>1️⃣ OpenAI 更新 GPT-5.5 Instant——Canvas 正式下线、写作/代码区块内嵌,o3 与 GPT-4.5 宣布退休时间表</b>
<i>🕐 05-30 · 距今约 18 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
OpenAI 于 5 月 30 日推送 GPT-5.5 Instant 模型更新:响应风格全面重调,减少冗余要点和超长回复,日常对话更自然流畅。同步宣布 Canvas 功能在 GPT-5.5 Instant 和 GPT-5.5 Thinking 中永久下线,写作与代码操作改由内嵌"写作区块"和"代码区块"承接;付费用户可在遗留模型中短暂续用 Canvas 直至其日落。此外正式公布两款旧模型退休时间表:GPT-4.5 于 2026-06-27 从 ChatGPT 下线,o3 于 2026-08-26 下线——均无官方博客或 X 公告,仅在 release notes 中静默更新。

<b>📊 关键数据</b>
- Canvas 下线范围：GPT-5.5 Instant &amp; GPT-5.5 Thinking（即时生效）
- GPT-4.5 退休：2026-06-27（30 天日落期）
- o3 退休：2026-08-26（90 天日落期）
- 改进方向：更短、更自然的回复，减少冗余列表与过长段落

<b>💡 为什么重要</b>
Canvas 无通知静默下线暴露 OpenAI"即时部署"模式的企业合规风险——客户缺乏迁移路径和预警期。o3 与 GPT-4.5 双双进入日落期，标志推理模型代际更替明显加速，企业须尽快评估依赖旧模型的工作流。

<b>2️⃣ OpenAI 推出 Rosalind Biodefense——向政府与受信开发者免费开放前沿生命科学推理模型 GPT-Rosalind</b>
<i>🕐 05-29 · 距今约 30 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
OpenAI 于 5 月 29 日正式发布 Rosalind Biodefense 计划，将其前沿生命科学推理模型 GPT-Rosalind 面向两类用户开放：①开发者通道：赞助 API 访问权限，支持流行病学建模、早期预警、筛查、非药物干预等公共卫生方向；②政府通道：为经审核的美国联邦机构及盟友合作伙伴提供 GPT-Rosalind 高级访问，支持生物防御与大流行病准备任务。GPT-Rosalind 于 2026 年 4 月首发，专为药物发现、基因组学和蛋白质推理设计。OpenAI 已就该计划向白宫及多个联邦机构进行简报。

<b>📊 关键数据</b>
- 模型：GPT-Rosalind（生命科学专用前沿推理模型，首发 2026-04）
- 两轨制接入：开发者（API 赞助） + 政府（审核制高级访问）
- 现有政府合作：DoD $2 亿飞行员项目、Los Alamos、Lawrence Livermore、Sandia、AWS GovCloud
- 定价：开发者通道由 OpenAI 赞助，政府通道费用未披露

<b>💡 为什么重要</b>
这是首次将前沿 AI 推理能力正式嵌入美国政府生物防御基础设施的举措，标志 AI 从辅助科研转向国家战略防御工具。这也是 OpenAI 在 IPO 前快速扩大政府客户基础、强化国家安全叙事的关键布局。

<b>3️⃣ 微软 Build 2026 前瞻:自研 AI 编码模型 Project Polaris 将取代 GitHub Copilot 对 OpenAI 的依赖</b>
<i>🕐 05-29 · 距今约 24 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
多家媒体于 5 月 29-30 日报道，微软计划在 6 月 2-3 日的 Build 2026 开发者大会（旧金山 Fort Mason）上发布一套自研 AI 模型，重点是代号 Project Polaris 的编码专用模型，将正式为 GitHub Copilot 提供动力。Polaris 采用混合专家（MoE）架构，针对不同编程语言和框架部署专属子模块，内部基准测试中在 HumanEval 和 MBPP 上超越 GPT-4 Turbo，尤其在 Rust、Haskell 等小语种语言优势显著。此举被视为微软在与 Anthropic 合作 Claude Code 成本飙升（Claude Code 授权将于 2026-06-30 终止）后，系统性降低对外部 AI 供应商依赖的战略转型。

<b>📊 关键数据</b>
- 发布时间：Build 2026，2026-06-02 至 06-03（旧金山）
- 架构：MoE（混合专家），针对语言/框架专属子模块
- 内部基准：超越 GPT-4 Turbo（HumanEval、MBPP），Rust/Haskell 优势突出
- GA 计划：新版 GitHub Copilot（由 Polaris 驱动）预计 2026 年 8 月 GA
- Claude Code 授权终止：2026-06-30

<b>💡 为什么重要</b>
微软此举宣告全球最大企业软件生态系统开始自研核心 AI 层，将压缩 Anthropic 和 OpenAI 在企业 API 市场的定价权，也预示"大厂自研 AI 替代第三方 API"将成为 2026 年下半年最重要的结构性趋势之一。
