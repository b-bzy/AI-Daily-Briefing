<b>1️⃣ Salesforce Agentforce Commerce 正式 GA：Shopper、Buyer、Merchant 三大 Agent 全面商用</b>
<i>🕐 06-29 · 距今约 24 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
Salesforce 于 6 月 29 日宣布 Agentforce Commerce 三大核心 Agent 全面正式可用（GA）：Shopper Agent 部署在品牌自有店面，自主回答问题并完成购买；Buyer Agent 通过 WhatsApp 或 SMS 处理 B2B 下单，无需登录门户；Merchant Agent 负责后台目录更新与促销管理。三大 Agent 已原生接入库存、订单管理和客户数据，可实时承诺到货时间并沿用合同定价，全程无需人工转接。同步发布的 Agentic B2C Developer Toolkit 引入统一 CLI、MCP Server 和 IDE 扩展，允许开发者用自然语言驱动 AI 编程代理完成组件部署与沙盒创建。

<b>📊 关键数据</b>
- 使用 AI 导购 Agent 的品牌销售增速比同行快 59%
- AI 已影响全球在线销售额的 20%，约合 2,620 亿美元（近一个节日季）
- ChatGPT 商品目录直连集成计划 7 月 GA，Google Search AI Mode 夏末跟进

<b>💡 为什么重要</b>
三大 Agent 覆盖 B2C 购物全链路和 B2B 下单场景，并通过 ChatGPT/Gemini 直连将商品目录推入主流 AI 交互入口，是 Salesforce 将 AI Agent 从演示功能推向商业核心的最明确一步。

<b>💡 为什么重要</b>
Claude 首次以原生 Azure 一体化方式向企业开放，消除了此前经 Amazon Bedrock 或独立 API 引入时的治理摩擦，预计将加速 Microsoft 企业客户向 Claude 的规模化迁移。

<b>3️⃣ GitHub Copilot 按量计费首个完整账单周期今日收官：开发者实账曝光，费用跳涨 10-100 倍</b>
<i>🕐 06-30 · 距今约 0 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
6 月 30 日是 GitHub Copilot 自 6 月 1 日切换 Token 用量计费后的首个完整账单周期收官日。开发者在 Reddit、X 和 GitHub 论坛陆续曝光实账截图：原 $29/月 Pro 用户预计账单跳升至 $750，原 $50/月用户跳升至 $3,000；重度 Agent 工作流用户单次代码修改请求耗费 $6 以上，月度 AI Credits 配额（7,000 单元）可能两天内耗尽。大批开发者宣布迁往 OpenRouter、RooCode 或直接调用 Anthropic/OpenAI API。

<b>📊 关键数据</b>
- 典型费用跳涨：$29 → $750；$50 → $3,000（重度 Agent 工作流场景）
- Pro+（$39/月）：部分用户 2 小时消耗月配额 8%，预估 2 天内耗尽
- 计费周期：2026 年 6 月 1 日起按 Token 计量，今日（6/30）首个完整周期结束
- 主要出走方向：OpenRouter、RooCode、LM Studio、直调 Anthropic/OpenAI API

<b>💡 为什么重要</b>
真实月度账单的规模化曝光是 AI 编程工具"按量计费"模式首次大规模实证考验；Agent 工作流下的费用放大效应远超预期，为 Cursor、Windsurf 等竞品提供了抢夺用户的黄金窗口，也将迫使 GitHub/微软重新审视计费策略。
