<i>🕐 05-05 · 距今约 48 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
Inworld AI 推出 Realtime TTS-2，自称业界首个"闭环"实时语音模型——不仅处理文字，还完整感知对话音频上下文，自动捕捉用户语调、节奏和情绪状态，并在 100+ 语言中保持同一声音身份。支持自然语言"语音指令"动态控制输出风格，以 Research Preview 形式通过 Inworld API 和 Realtime API 开放接入。

<b>📊 关键数据</b>
- 支持语言：100+（跨语言保持声音身份一致）
- 核心能力：闭环音频感知 + 自然语言语音方向控制
- 接入方式：Inworld API、Realtime API（Research Preview）

<b>💡 为什么重要</b>
现有 TTS 模型只"读"文字；Realtime TTS-2 在对话中实时"听"并动态调整，使 Voice Agent 更接近真实对话体验，对实时语音 Agent 平台（销售外呼、AI 客服、陪伴）形成直接升级。
