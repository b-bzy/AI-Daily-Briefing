<b>1️⃣ Salesforce Summer '26 Sandbox 预览上线：Agentforce for Sales 资质评估扩展至联系人与个人账户</b>
<i>🕐 05-08 · 距今约 24 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
Salesforce 于 5 月 8 日向 Sandbox 开放 Summer '26 版本早期预览，正式全量发布预计 2026 年 7 月。本次核心更新：① Agentforce for Sales 将自动资质评估能力从线索（Lead）扩展至联系人（Contact）和个人账户（Person Account），支持基于 ICP（理想客户画像）的自动匹配评分；② 新增 SIP 协议语音通话路由，Agentforce Service Agent 可通过企业 PBX/SIP 接入，不再局限于 PSTN 号码；③ 通过 Salesforce 移动端即时捕获面对面会议内容，Einstein Conversation Insights 自动生成摘要与待办事项；④ 面向开发者发布 Agentforce DX MCP Server，简化自定义 Agent 的构建与调试。

<b>📊 关键数据</b>
- Sandbox 预览开放日：2026 年 5 月 8 日
- 正式发布预计：2026 年 7 月
- 新支持协议：SIP（原仅限 PSTN）
- 资质评估新覆盖对象：Contact 和 Person Account（原仅 Lead）

<b>💡 为什么重要</b>
企业 B2B 销售团队的核心工作场景是已有客户联系人（Contact），而非原始线索；Agentforce 将资质评估能力下沉至 Contact 层，意味着 AI 销售助手可直接参与关键账户的商机深挖，对高客单价 B2B 和关键客户管理（KAM）场景尤为关键。

<b>1️⃣ Anthropic 于 Code with Claude 大会发布三大 Managed Agents 新能力：Dreaming 让 Agent 任务间自主"进化"</b>
<i>🕐 05-06 · 距今约 57 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
Anthropic 在旧金山 Code with Claude 开发者大会（5 月 6 日）推出三项 Claude Managed Agents 新功能：① Dreaming（Research Preview）：在 Agent 会话间隙后台自动运行的调度进程，持续回顾历史对话、提取重复规律并更新记忆库，使 Agent 在多次任务中积累经验；法律 AI 公司 Harvey 启用后，Agent 任务完成率提升约 6 倍；② Outcomes（Public Beta）：开发者以自然语言定义成功评分标准（Rubric），Agent 自主驱动任务直至达标，Anthropic 内部基准相比标准提示循环任务成功率最高提升 10 个百分点；③ Multiagent Orchestration（Public Beta）：主 Agent 将复杂任务分解，委派给各具独立模型、提示词与工具的子 Agent 并行执行后汇总。

<b>📊 关键数据</b>
- Dreaming：Research Preview 开放
- Outcomes + Multiagent Orchestration：Public Beta
- Outcomes 内部基准：任务成功率最高 +10 个百分点
- Harvey 案例：Agent 任务完成率约 6 倍提升

<b>💡 为什么重要</b>
Dreaming 是行业首个将"跨会话经验积累"机制商业化内置于 Agent 平台的实现；Outcomes 将 Agent 对齐从提示工程层面升至目标驱动层面。三项能力叠加，标志 Claude Managed Agents 向"自主演化型 Agent"迈出关键一步，对编程、法律、金融等高复杂度 Agent 场景影响深远。
