<b>1️⃣ MiniMax 发布 Speech 2.8：原生音效标签 + 40+ 语言，旗舰 TTS 再升级</b>
<i>🕐 04-28 · 今日发布</i>
<blockquote expandable><b>📝 发生了什么</b>
MiniMax 今日正式发布 Speech 2.8，旗舰 TTS 系列最新一代，分 Turbo（低延迟/低成本）与 HD（广播级音质）两个版本。相较 Speech 2.6，新版增加原生音效标签支持（可插入 [cough]、[laugh] 等副语言标签），语言覆盖从约 32 种扩展至 40+ 种，情感模式从 5 种升至 7 种，声音克隆音色相似度与音调细腻度进一步提升。

<b>📊 关键数据</b>
- 语言支持：40+ 种（Speech 2.6 为约 32 种）
- 情感模式：7 种（Speech 2.6 为 5 种）
- 原生音效标签：支持插入语气词、笑声等副语言特征
- 两版本：Turbo（速度优先）、HD（广播级高保真）

<b>💡 为什么重要</b>
MiniMax 是中国头部语音 AI 厂商之一，Speech 2.8 发布正值 Mistral Voxtral、小米 MiMo 等密集入场期，进一步加剧全球 TTS 赛道竞争；原生音效标签与情感能力升级，有助于语音 Agent 在销售外呼和客服场景实现更自然的对话体验。

<b>2️⃣ Microsoft 与 OpenAI 重写合作协议：OpenAI 获多云自由，微软停收营收分成</b>
<i>🕐 04-27 · 距今约 10 小时</i>
<blockquote expandable><b>📝 发生了什么</b>
微软与 OpenAI 于 4 月 27 日联合宣布修订合作协议：OpenAI 可面向所有云服务商（含 Google Cloud、AWS）部署产品，Azure 保留"首发优先"地位；微软将不再向 OpenAI 支付营收分成，但 OpenAI 仍须向微软支付分成（设有上限）至 2030 年；微软对 OpenAI 的 IP 授权延续至 2032 年但改为非独占。此次修订直接解锁了 OpenAI 此前与 Amazon $500 亿合作所面临的法律障碍。

<b>📊 关键数据</b>
- OpenAI 多云部署：可正式使用 Google Cloud 等竞争云平台
- 微软 IP 授权：延续至 2032 年，由独占改为非独占
- OpenAI 向微软支付分成：持续至 2030 年，设上限
- 微软仍为 OpenAI 重要股东，Azure 保持"首发优先"权

<b>💡 为什么重要</b>
OpenAI 正式向"云中立"转型，不再被绑定 Azure 单一平台；对微软而言，失去营收分成但换来法律确定性；Google Cloud 将成 OpenAI 第二大云合作伙伴，云 AI 市场格局深刻重塑。
